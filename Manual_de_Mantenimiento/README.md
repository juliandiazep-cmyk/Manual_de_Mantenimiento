# Plano de mantenimiento de un computador

Manual web sobre mantenimiento preventivo y correctivo de una PC de escritorio y una laptop.
Creador: Julián Enrique Díaz Palmera.

## Estructura
- `index.html`: estructura y textos fijos.
- `css/styles.css`: estilo de plano técnico.
- `js/app.js`: datos (pasos y fallas) y lógica (botones, progreso, diagnóstico).

## Cómo verla
Abre `index.html` en el navegador. No requiere instalar nada.
